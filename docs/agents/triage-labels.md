# Triage Labels

工程 Skills 使用五个规范角色。下表定义它们在本仓库 GitHub Issues 中对应的标签。

| Skill 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 独立实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 决定不处理 |

当 Skill 使用“AFK-ready”等角色语义时，以此表对应的 GitHub 标签为准。
