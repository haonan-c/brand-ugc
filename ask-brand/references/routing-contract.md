# Ask Brand 路由合同

## 明确意图

- 选题雷达、每日选题、生成选题、热点选题、需求词、搜索联想、话题研究、Topic Radar → `xhs-topic-radar`
- 图文、小红书、图片、笔记、封面、内页、Carousel → `ugc-image-post`
- 视频、短视频、分镜、Seedance、Storyboard → `ugc-storyboard`
- 品牌档案、品牌规范、品牌语气、Brand Profile → `brand-profile`

明确意图不重复询问路径，只检查必填素材。仅出现“小红书”或“笔记”仍按图文生产理解，不据此推断选题研究；选题雷达必须出现更具体的研究或选题词。

同时明确要求选题研究和图文/视频生产时，返回 `needs_confirmation` 并只询问一次执行顺序，推荐先完成选题雷达。不得在一次路由中隐式执行两条工作流。

## 模糊意图

- 只有完整图文素材 → 推荐 `ugc-image-post`
- 只有完整视频素材 → 推荐 `ugc-storyboard`
- 两组素材都完整 → 推荐先用图文验证表达，但必须确认
- 素材不足且意图不明 → 询问先做图文还是短视频

一次回复只能提出一个路由问题。用户没有明确要求时，不同时执行两个生产 Skill。

## 必填素材

`ugc-image-post`：

- 1–9 张有顺序的对标图片
- 对标文案
- 产品图

`ugc-storyboard`：

- 对标视频
- 产品图

品牌档案对两个生产路径都是可选输入。

`xhs-topic-radar` 不要求本地素材，但要求行业、回看周期和用户自己的 TikHub 凭据。需求词预览后必须等待费用确认，不能由路由器代替用户批准。
